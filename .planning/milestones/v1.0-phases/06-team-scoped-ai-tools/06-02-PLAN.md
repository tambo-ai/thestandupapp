   - Keep `initialMessages` with the system prompt.

   - Include write operation restriction: "NEVER perform write operations using another member's account. ALL writes use current user's credentials only."

   - Include response style: brief chat, rich data in canvas components, standup-relevant data prioritized
   - Include mode-aware placeholder comment: `// Phase 7: Live standup mode will extend this prompt with structured round-robin behavior`

   - Keep the selected team context and component instructions from the existing prompt
