Fix the anti-pattern identified in VERIFICATION.md where the auto-select block (line 166) reads `request.cookies.get('active_team_id')` after potentially deleting it from `response.cookies` (line 161). Since `request.cookies` reflects the original request (not mutations), the deletion is invisible.

Change line 166 from:
```typescript
const currentActiveTeam = request.cookies.get('active_team_id')?.value;
```
to read from the response cookies instead, or track the deletion state:
```typescript
// After the validation block (step 7), track whether the cookie is still valid
let hasValidActiveTeam = !!activeTeamId && !!membership;
```

Then at step 8, use `hasValidActiveTeam` instead of re-reading the cookie:
```typescript
if (!hasValidActiveTeam) {
  // ... auto-select logic
}
```

This ensures that if the cookie was just invalidated and deleted in step 7, the auto-select block in step 8 correctly detects that no valid team is selected and proceeds to auto-select.
