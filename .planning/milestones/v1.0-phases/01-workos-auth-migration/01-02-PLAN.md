  **2. Create `src/app/app/page.tsx`** as a SERVER component for the protected `/app` route:
  ```typescript
  import { withAuth } from '@workos-inc/authkit-nextjs';
  import { AppShell } from './app-shell';

  export default async function AppPage() {
    const { user, accessToken } = await withAuth({ ensureSignedIn: true });

    return (
      <AppShell
        userId={user.id}
        userName={`${user.firstName ?? ''} ${user.lastName ?? ''}`.trim() || user.email}
        userEmail={user.email}
        userImage={user.profilePictureUrl ?? undefined}
        userToken={accessToken}
      />
    );
  }
  ```
  - `ensureSignedIn: true` means middleware + withAuth will redirect unauthenticated users to WorkOS login
  - Pass `accessToken` as `userToken` for TamboProvider (replaces Better Auth's `session.session.token`)
  - Fallback to `user.email` if both firstName and lastName are null

  **3. Create `src/app/app/app-shell.tsx`** as a CLIENT component extracted from the current `src/app/page.tsx`:
  - Add `"use client"` at the top
  - Define a `Props` interface: `{ userId: string; userName: string; userEmail: string; userImage?: string; userToken: string }`
  - Export `AppShell` as a named export (not default) that accepts these props
  - Copy the entire `AppShell` function body from the current `src/app/page.tsx` but:
    - REMOVE `const { data: session, isPending } = authClient.useSession()` and ALL derived state from session
    - REMOVE `import { authClient } from "@/lib/auth-client"` entirely
    - REMOVE `const userId = session?.user?.id` -- use `props.userId` instead
    - REMOVE `const userName = session?.user?.name ?? ""` -- use `props.userName`
    - REMOVE `const userEmail = session?.user?.email ?? ""` -- use `props.userEmail`
    - REMOVE `const userToken = session?.session?.token` -- use `props.userToken`
    - REMOVE `if (isPending || !userToken) return null` -- server component guarantees user data
    - Pass `props.userName`, `props.userImage` to `<UserHeader>` as props (see Task 2 for UserHeader changes)
    - Keep ALL other logic: selectedTeam state, filteredMemberNames, useEffect for setTokenUserId, buildSystemPrompt, chatWidth/dragging/onDragStart, TamboProvider with components/tools/initialMessages
    - Keep the `buildSystemPrompt` function as-is (it uses userName and userEmail which now come from props)
  - Keep all existing imports except `authClient`
