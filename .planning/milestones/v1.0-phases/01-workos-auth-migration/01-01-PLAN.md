  <action>
  Create/modify 5 files:

  **1. Replace `src/middleware.ts`** with WorkOS authkitMiddleware:
  ```typescript
  import { authkitMiddleware } from '@workos-inc/authkit-nextjs';

  export default authkitMiddleware({
    middlewareAuth: {
      enabled: true,
      unauthenticatedPaths: ['/', '/api/auth/callback'],
    },
  });

  export const config = {
    matcher: [
      '/',
      '/app/:path*',
      '/api/auth/callback',
    ],
  };
  ```
  IMPORTANT: Do NOT use a catch-all regex matcher -- it breaks Tailwind CSS v4 by intercepting static asset requests (documented in RESEARCH.md Pitfall 1). Use explicit route matchers only.

  **2. Create `src/app/api/auth/callback/route.ts`**:
  ```typescript
  import { handleAuth } from '@workos-inc/authkit-nextjs';

  export const GET = handleAuth({ returnPathname: '/app' });
  ```
  This processes the OAuth callback from WorkOS and redirects authenticated users to `/app` (per CONTEXT.md: AUTH-04 redirect to intended destination).

  **3. Create `src/lib/auth-actions.ts`**:
  ```typescript
  "use server";

  import { signOut } from "@workos-inc/authkit-nextjs";

  export async function logout() {
    await signOut({ returnTo: "/" });
  }
  ```
  This is a server action file. The `"use server"` directive at the top is required because `signOut` is a server-only function and cannot be imported directly in client components (RESEARCH.md Pitfall 3). After logout, redirect to `/` landing page per CONTEXT.md.

  **4. Update `src/app/layout.tsx`** to wrap the app with AuthKitProvider:
  - Import `AuthKitProvider` from `'@workos-inc/authkit-nextjs/components'`
  - Wrap `{children}` inside `<AuthKitProvider>` within the `<body>` tag
  - Keep all existing font setup, metadata, className, etc. unchanged
  - The AuthKitProvider provides protections for auth edge cases (RESEARCH.md Pattern 5)

  **5. Replace `example.env.local`** with WorkOS variables:
  ```
  NEXT_PUBLIC_TAMBO_API_KEY=api-key-here

  WORKOS_CLIENT_ID=client_01H...
  WORKOS_API_KEY=sk_test_...
  WORKOS_COOKIE_PASSWORD=generate-with-openssl-rand-base64-32
  NEXT_PUBLIC_WORKOS_REDIRECT_URI=http://localhost:3000/api/auth/callback

  TURSO_DATABASE_URL=libsql://your-db.turso.io
  TURSO_AUTH_TOKEN=your-turso-auth-token
  ```
  Remove BETTER_AUTH_SECRET, BETTER_AUTH_URL, GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET. Keep TAMBO and TURSO vars.
