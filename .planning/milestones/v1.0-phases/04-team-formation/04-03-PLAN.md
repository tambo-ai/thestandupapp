**src/app/invite/[token]/page.tsx** -- Server component (public route):

This is a Next.js dynamic route at `/invite/[token]`. It's a server component that handles both authenticated and unauthenticated users.

Implementation:
1. Extract `token` from `params.token`
2. Look up invite link in DB:
   ```typescript
   const fullDb = getFullDb();
   const invite = await fullDb
     .selectFrom('invite_links')
     .innerJoin('teams', 'teams.id', 'invite_links.team_id')
     .where('invite_links.token', '=', token)
     .where('invite_links.revoked_at', 'is', null)
     .select(['invite_links.id', 'invite_links.team_id', 'invite_links.max_uses',
              'invite_links.use_count', 'invite_links.expires_at',
              'teams.name as team_name', 'teams.workos_organization_id'])
     .executeTakeFirst();
   ```
3. If not found: render error page -- "This invite link is no longer valid. Ask the team owner for a new one."
4. If expired (expires_at && new Date(expires_at) < new Date()): render error page -- "This invite link has expired."
5. If max_uses reached: render error page
6. Try to get session: `const { user } = await withAuth()` (WITHOUT ensureSignedIn -- this is a public page)
7. If user is authenticated:
   - Check if already a member: query memberships where user_id = user.id AND team_id = invite.team_id
   - If already member: redirect to /app (use Next.js `redirect('/app')` from 'next/navigation')
   - If not a member: render page with team name + "Join [Team]" button that triggers JoinSection client component
8. If user is NOT authenticated:
   - Render page with team name + "Join [Team]" button
   - The Join button for unauth users MUST set a `pending_invite_token` cookie before redirecting to sign-in

9. Welcome screen after successful join: show "Welcome to [Team]!" with the team name and a "Go to workspace" button that navigates to /app.

10. Page styling: Clean, centered card layout. Team name prominent. Simple call-to-action button. Error states clearly communicated with suggestion to request new invite.

11. Create a client component within the same file (or a separate file) for the interactive join button:
   ```typescript
   'use client';
   import { joinTeam, setPendingInvite } from '@/lib/team-actions';

   function JoinSection({ token, teamName, isAuthenticated }: { token: string; teamName: string; isAuthenticated: boolean }) {
     // State: idle | loading | joined | error
     const [state, setState] = useState<'idle' | 'loading' | 'joined' | 'error'>('idle');
     const [joinedTeamName, setJoinedTeamName] = useState('');

     async function handleJoin() {
       if (!isAuthenticated) {
         // Set pending_invite_token cookie via server action, then redirect to sign-in
         await setPendingInvite(token);
         // Redirect to sign-in. The auth callback (Plan 04) will read the cookie and auto-join.
         window.location.href = '/';  // Landing page triggers WorkOS sign-in
         return;
       }

       // Authenticated: call joinTeam server action directly
       setState('loading');
       try {
         const result = await joinTeam(token);
         if ('alreadyMember' in result) {
           window.location.href = '/app';
           return;
         }
         setJoinedTeamName(result.teamName);
         setState('joined');
       } catch (err) {
         setState('error');
       }
     }

     // Render based on state:
     // idle: "Join [teamName]" button
     // loading: spinner
     // joined: "Welcome to [joinedTeamName]!" + "Go to workspace" button (links to /app)
     // error: "Something went wrong" + retry button
   }
   ```

IMPORTANT: The `setPendingInvite` server action (from Plan 01) MUST be called for unauthenticated users. This is the critical link that enables auto-join on auth callback. Do NOT leave this as a "may need" or "TODO" -- it must be implemented in this task.
