Create three API route files following the established withAuth + ownership check pattern from invite-link/route.ts.

**src/app/api/teams/leave/route.ts** (POST):
- Accept `{ teamId }` from body
- withAuth({ ensureSignedIn: true }) to get user
- Verify user is a member of the team via memberships table
- If user's role is "owner", count owners for that team. If count === 1, return 400 with error: "You're the only owner. Transfer ownership before leaving."
- Look up team's workos_organization_id from teams table
- Delete local membership from memberships table (WHERE user_id = user.id AND team_id = teamId)
- If team has workos_organization_id, look up WorkOS org membership via `listOrganizationMemberships({ organizationId, userId: user.id })` and delete it via `deleteOrganizationMembership(id)`. Wrap in try/catch -- log error but don't block on WorkOS failure.
- Find user's personal workspace: SELECT teams.id, teams.workos_organization_id FROM teams INNER JOIN memberships ON memberships.team_id = teams.id WHERE memberships.user_id = user.id AND teams.is_personal = 1
- Return 200 with `{ personalTeamId, personalWorkosOrgId }` for client redirect

**src/app/api/teams/members/route.ts** (extend with DELETE):
- Keep existing GET handler unchanged
- Add DELETE handler accepting `{ teamId, userId: targetUserId }` from body
- withAuth({ ensureSignedIn: true })
- Verify requesting user is owner of the team (role check)
- Verify target user is a member and is NOT an owner (cannot remove owners)
- Look up team's workos_organization_id
- Delete target's local membership
- If team has workos_organization_id, find and delete WorkOS org membership for target user. Try/catch, log on failure.
- Return 200 with `{ removed: true }`

**src/app/api/teams/invitations/route.ts** (GET + POST):

GET handler:
- Accept teamId from query params
- withAuth({ ensureSignedIn: true })
- Verify user is a member of the team
- Fetch WorkOS email invitations: `workos.userManagement.listInvitations({ organizationId: team.workos_organization_id })` -- filter to state === "pending"
- Fetch local invite links: SELECT from invite_links WHERE team_id = teamId AND revoked_at IS NULL
- For each WorkOS invitation, look up inviter name from users table by inviterUserId (if available)
- For each invite link, look up creator name from users table by created_by
- Return merged JSON: `{ invitations: [...emailInvitations, ...linkInvitations] }` where each item has: `{ id, type: "email" | "link", email?: string, useCount?: number, invitedBy: string, createdAt: string, token?: string, url?: string }`
- For link invitations, include the full URL (same pattern as invite-link GET route)

POST handler (actions):
- Accept `{ teamId, action, invitationId, type }` from body
- action is one of: "resend", "revoke"
- withAuth + verify owner
- If type === "email": use WorkOS `resendInvitation(invitationId)` or `revokeInvitation(invitationId)`
- If type === "link" and action === "revoke": revoke the local invite_link by setting revoked_at, then auto-regenerate a new one (same pattern as invite-link POST route -- revoke all, create new). Return the new link data.
- If type === "link" and action === "resend": return 400 (links cannot be resent)
- Return 200 with `{ success: true }` (plus new link data for link revocations)

**src/app/api/teams/update/route.ts** (PATCH):

- withAuth({ ensureSignedIn: true })

**src/app/api/teams/delete/route.ts** (POST):
- Accept `{ teamId, confirmName }` from body
- withAuth({ ensureSignedIn: true })
- Verify requesting user is owner of the team
- Verify team is NOT personal (is_personal !== 1). Return 400 if personal.
- Load team name. Verify confirmName matches team name exactly. Return 400 with `{ error: "Team name doesn't match" }` if not.
- Delete in order to avoid FK issues:
  1. Revoke all invite links: UPDATE invite_links SET revoked_at = now() WHERE team_id = teamId
  2. Delete all invite links: DELETE FROM invite_links WHERE team_id = teamId
  3. Delete all connections: DELETE FROM connections WHERE team_id = teamId
  4. Delete all memberships: DELETE FROM memberships WHERE team_id = teamId
  5. Delete team: DELETE FROM teams WHERE id = teamId
  6. If team had workos_organization_id: `workos.organizations.deleteOrganization(orgId)`. Try/catch, log on failure.
- Find user's personal workspace (same query as leave route)
- Return 200 with `{ deleted: true, personalTeamId, personalWorkosOrgId }`
