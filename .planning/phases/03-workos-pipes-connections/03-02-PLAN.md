The modal contains the embedded WorkOS Pipes widget which handles all connect/disconnect/reauth flows natively. Per user decisions:
- Title: "Connect your accounts" (no subtitle)
- Uses createPortal (existing modal pattern)
- Backdrop blur + click-outside-to-close + Escape key to close

Structure:
```typescript
'use client';
import { useAccessToken } from '@workos-inc/authkit-nextjs/components';
import { Pipes, WorkOsWidgets } from '@workos-inc/widgets';
import { X } from 'lucide-react';
```

Props: `{ isOpen: boolean; onClose: () => void }`

Implementation:
1. Get `{ getAccessToken }` from `useAccessToken()` hook
2. If `!isOpen` return null
3. Handle Escape key with useEffect (same pattern as settings-modal)
4. Render portal with:
   - Fixed overlay with `z-50`, rgba backdrop + blur
   - Click-outside-to-close on overlay
   - White rounded-2xl container, max-w-[420px]
   - Header: "Connect your accounts" (text-[15px] font-semibold) + X close button
   - Body: `<WorkOsWidgets><Pipes authToken={getAccessToken} /></WorkOsWidgets>`

The Pipes widget renders its own cards for each configured provider (GitHub and Linear, as configured in WorkOS Dashboard). It handles the full OAuth flow, status display, connect/disconnect/reauth. We do NOT need to build custom cards — the widget IS the card UI.

Per user decision on disconnect: The widget handles disconnect internally with its own confirmation flow. If the widget's native flow differs from the "inline confirmation" decision, that's acceptable since the widget controls this UX.

Style the container to match existing app aesthetics (white bg, subtle border, rounded corners). Keep it clean and simple — the widget does the heavy lifting.

**src/app/app/app-shell.tsx** — Wire everything together.

1. Add import for ConnectionsModal from `@/components/connections-modal`
2. Add import for ConnectionPrompt from `@/components/connection-prompt`
3. Add state: `const [modalOpen, setModalOpen] = React.useState(false)`
4. Add state: `const [connStatus, setConnStatus] = React.useState(connectionStatus ?? { github: 'not_installed', linear: 'not_installed' })`
5. Add function to refresh connection status from API:
   ```typescript
   const refreshConnectionStatus = React.useCallback(async () => {
     try {
       const res = await fetch('/api/connections/status');
       const data = await res.json();
       setConnStatus(data);
     } catch { /* ignore */ }
   }, []);
   ```
6. When modal closes, refresh status:
   ```typescript
   const handleModalClose = React.useCallback(() => {
     setModalOpen(false);
     refreshConnectionStatus();
   }, [refreshConnectionStatus]);
   ```
7. Pass to UserHeader: `connectionStatus={connStatus}` and `onOpenModal={() => setModalOpen(true)}`
8. Determine if user has no connections: `const hasNoConnections = connStatus.github !== 'connected' && connStatus.linear !== 'connected';`
9. Conditionally render ConnectionPrompt in the chat panel area (before MessageThreadFull), only when `hasNoConnections`:
   ```tsx
   {hasNoConnections && <ConnectionPrompt onOpenModal={() => setModalOpen(true)} />}
   ```
10. Render `<ConnectionsModal isOpen={modalOpen} onClose={handleModalClose} />` at the end of the component (outside TamboProvider is fine since it uses createPortal)
