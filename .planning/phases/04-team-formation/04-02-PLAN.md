All routes follow the same pattern: import withAuth + getWorkOS, validate request body, perform DB + WorkOS operations, return JSON response. Use NextResponse.json() for all responses.

**POST /api/teams/create/route.ts:**
- `withAuth({ ensureSignedIn: true })` to get user
- Parse JSON body: `{ name: string, slug: string }`
- Validate: name 1-100 chars, slug 3-50 chars matching /^[a-z0-9][a-z0-9-]*[a-z0-9]$/ (or 3 chars if no hyphens)
- Check slug uniqueness: `db.selectFrom('teams').where('slug', '=', slug).select('id').executeTakeFirst()`
- If taken: return 409 `{ error: "Slug already taken" }`
- Soft limit check: count user's non-personal teams. If >= 5, log warning but proceed (per user decision)
- Create WorkOS Organization: `getWorkOS().organizations.createOrganization({ name })`
- Transaction via getFullDb(): INSERT team (id, name, slug, is_personal: 0, workos_organization_id: org.id) + INSERT membership (team_id, user_id, role: 'owner')
- Create WorkOS org membership: `workos.userManagement.createOrganizationMembership({ organizationId: org.id, userId: user.id, roleSlug: 'admin' })`
- Create default invite link: INSERT into invite_links (id, team_id, created_by, token: randomUUID)
- Set active_team_id cookie to the new team's ID via cookies().set() with same settings as existing setActiveTeam (httpOnly, sameSite: 'lax', path: '/', secure in production, maxAge: 30 days). This ensures the user lands in the new workspace on reload per CONTEXT.md locked decision.
- Return 201 `{ id: teamId, name, slug, workosOrgId: org.id }`
- Do NOT call switchToOrganization here -- the client will call the switchTeam server action after creation to handle the WorkOS session switch (which may redirect)

**POST /api/teams/switch/route.ts:**
- `withAuth({ ensureSignedIn: true })` to get user
- Parse JSON body: `{ teamId: string, workosOrgId: string | null }`
- Import and delegate to `switchTeam` server action from `@/lib/team-actions`. This keeps switchToOrganization inside a server action where its redirect behavior is handled correctly by Next.js (per research pitfall -- switchToOrganization called inside an API route throws a redirect that fetch() cannot handle).
- The switchTeam server action verifies membership, sets the cookie, and calls switchToOrganization for non-personal teams.
- Return 200 `{ success: true }` -- NOTE: if switchToOrganization redirects, this response won't be reached. The client should handle this by doing a full page reload regardless of response.

**GET /api/teams/members/route.ts:**
- `withAuth({ ensureSignedIn: true })` to get user
- Read teamId from query param: `request.nextUrl.searchParams.get('teamId')`
- If no teamId: return 400 `{ error: "teamId required" }`
- Verify user is member of this team
- Query: getFullDb().selectFrom('memberships').innerJoin('users', 'users.id', 'memberships.user_id').where('memberships.team_id', '=', teamId).select(['users.id', 'users.name', 'users.email', 'users.avatar_url', 'memberships.role']).orderBy('memberships.role', 'asc').orderBy('users.name', 'asc').execute()
- Return 200 `{ members: [...] }`

**GET + POST /api/teams/invite-link/route.ts:**

GET handler:
- `withAuth({ ensureSignedIn: true })`
- Read teamId from query param
- Verify membership
- Query: getFullDb().selectFrom('invite_links').where('team_id', '=', teamId).where('revoked_at', 'is', null).select(['token', 'use_count', 'created_at']).orderBy('created_at', 'desc').executeTakeFirst()
- If no link exists, create one: INSERT invite_links (id, team_id, created_by, token: randomUUID)
- Return 200 `{ token: link.token, url: `${process.env.NEXT_PUBLIC_APP_URL || 'http://localhost:3000'}/invite/${link.token}`, useCount: link.use_count }`

POST handler (regenerate):
- `withAuth({ ensureSignedIn: true })`
- Parse JSON body: `{ teamId: string }`
- Verify user is OWNER of this team (role check on membership)
- If not owner: return 403 `{ error: "Only the team owner can regenerate invite links" }`
- Revoke all existing links: UPDATE invite_links SET revoked_at = datetime('now') WHERE team_id AND revoked_at IS NULL
- Create new link: INSERT invite_links (id, team_id, created_by: user.id, token: randomUUID)
- Return 201 `{ token, url }`

**POST /api/teams/invite-email/route.ts:**
- `withAuth({ ensureSignedIn: true })`
- Parse JSON body: `{ teamId: string, emails: string }` (comma-separated)
- Verify membership (any member can invite per user decision)
- Look up team to get workos_organization_id; if null return 400 (personal teams can't invite)
- Parse emails: split by comma, trim, filter empty, validate basic email format
- If no valid emails: return 400 `{ error: "No valid email addresses" }`
- Cap at 10 emails per batch to avoid abuse
- Send invitations via Promise.allSettled: `workos.userManagement.sendInvitation({ email, organizationId: team.workos_organization_id, inviterUserId: user.id, expiresInDays: 7 })`
- Return 200 `{ sent: successCount, failed: failedEmails[] }`

**POST /api/teams/join/route.ts:**
- `withAuth({ ensureSignedIn: true })`
- Parse JSON body: `{ token: string }`
- Import and delegate to `joinTeam` server action from `@/lib/team-actions`. This keeps the join logic in one place (server action) and the API route is a thin wrapper.
- Return appropriate status codes: 201 for joined, 200 for alreadyMember, 404/410 for invalid tokens.
- Alternatively, implement inline if the server action's return type doesn't map cleanly to HTTP responses. In that case, replicate the join logic here but keep it consistent with the server action.
